# Chaos Zero Nightmare Fan Guide Repository

A comprehensive fan-made knowledge base for **Chaos Zero Nightmare (CZN)**, the roguelike deck-building RPG developed and published by Smilegate, launched globally on October 22, 2025 across PC, Android, and iOS.

This repository compiles verified data, mechanical breakdowns, character profiles, card databases, and progression guides.

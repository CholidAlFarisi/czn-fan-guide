⚡ Aether (Stamina) Allocation

  • Early Game: Spend 100% on Main Campaign to unlock Simulation modes.
  • Level 25+: Farm Simulation: Memory Fragments (60 Aether/run) for core gear sets.
  • Daily Routine: Never let Aether cap—visit the Garden Café in Ark City to claim 80 free daily Aether.

📅 Daily Captain Routine

  • Clear all Daily Missions for steady pull crystals and upgrade tokens.
  • Spend 3 Communication Passes in Ark City to raise Hero Affinity.
  • Dispatch agents at the Policy Office to earn Nono Shop points.
  • Treat agents with Deep Trauma at the Epione Center.

Hero Investment Priority

1. Rank Promotion
Breakthrough levels at 20/40/60/80 using Striker Manuals to unlock higher base stats and card skill upgrades.
2. Potential Skill Tree
Unlock character-specific nodes that permanently mutate starting card effects and enhance critical multipliers.
3. Memory Fragments
Farm set bonuses (4-piece Attack / 2-piece Defense) to reinforce baseline survival before entering Chaos zones.
4. Save Data Carryover
Lock optimal high-roll Epiphany cards and rare relics in the Zero System to create perfect loadouts.

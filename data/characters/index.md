## Character Classes

| Class | Role Description |
| :--- | :--- |
| **Striker** | Primary DPS melee combatants specializing in aggressive damage output and combo chains |
| **Hunter** | Ranged DPS units focusing on precision targeting, bullets, and tracking mechanics |
| **Vanguard** | Frontline tank/defense specialists excelling at shield generation and damage absorption |
| **Psionic** | Esoteric support units wielding summoning, creation, and healing abilities |
| **Ranger** | Versatile ranged attackers with ballista, artillery, and battlefield control |
| **Controller** | Tactical support units specializing in card manipulation, debuffs, draws, and quest mechanics |

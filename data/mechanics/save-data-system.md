# Save Data System

The **Save Data System** is the persistent progression framework bridging roguelike Chaos runs with permanent character loadouts. At the conclusion of every Chaos run, the game generates **Save Data** for the combatants used — a snapshot of your build constrained by a **power budget**.

---

## 1. Core Concept

Save Data is essentially a **loadout snapshot** that can be equipped for other game modes (story missions, daily simulations, Zero System codices, PvP-like ranking content). It represents what your character brings into a fight, independent of gacha ascension.

---

## 2. Power Budget Constraint

Save Data is not unlimited. It is bound by a **Save Data Value** (also referred to as TB Value or PT Value):
- **Guaranteed Carryover Elements:**
  - Unique character cards
  - Equipment
  - Epiphanies
- **Limited Elements:**
  - Common cards
  - Duplicates
  - Additional cards added during the run
- **Exceeding the Budget:** When the budget is exceeded, you must remove cards or downgrade elements before the Save Data can be finalized and equipped.

---

## 3. Quality Scaling

| Factor | Effect on Save Data |
| :--- | :--- |
| **Higher difficulty tier** | Better Save Data quality (higher budget, better rolls) |
| **Deeper Chaos level** | Improved rarity of carried Epiphanies |
| **Zero System / Codex completion** | Additional upgrade stages and Divine Representative encounters |

---

## 4. 2026 Zero System Rework

The 2026 Zero System overhaul introduced significant Save Data upgrades:
- **3 Upgrade Stages:** Each stage boosts **Epiphany rates** and improves Save Data generation quality.
- **Divine Representative Encounters:** Added as rare, high-value encounters during runs.
- **Card Add/Remove:** Both adding and removing cards **exhausts the Save Data limit** — every modification counts against the budget.
- **Impact Level:** Save Data is described as the **most impactful upgrade element** in the game, though it takes considerable time to optimize.

---

## 5. Practical Notes

- **Save Data is the loadout** for other modes — treat a completed run as a "build artifact" you carry forward.
- Prioritize **unique cards + Epiphanies + equipment** as the core of your budget; trim common card bloat.
- **Deep Trauma runs** and **Nightmare difficulty** produce superior Save Data at the cost of much higher run risk.
- Save Data optimization is a long-term project — expect to iterate across many runs.
